AI & Music 2026 · hackathon

Audio Workbench
built by an agent cascade

Humans write an EPIC and merge the final PR. Devin agents do everything in between: spec, task breakdown, TDD implementation, review, escalation.

The problem

A two-day build has no room for a human in the middle

  • Turning one feature idea into a spec, tasks, branches and PRs eats the hours a hackathon does not have.
  • Audio work compounds it: WebAudio timing, librosa analysis and a shared API contract must all move together.
  • Handoffs between people are where context, tests and typing get lost.

The bottleneck is coordination, not typing speed.

Why an agent cascade

Zero Human Middle

Spec first

A TPM agent turns /devin architect on an EPIC into docs/specs/*.md before any code exists.

Atomic tasks

One issue, one branch, one PR per task. Workers run TDD and every quality gate before opening a PR.

Loud failure

Three strikes → BLOCKED: human-attention → Discord pager. No silent loops.
