There are many collaboration scenarios depending on which local or remote data sources and data destinations are used. For example:

- \[OscGroups / XR-Animator\] -\> SuperCollider -\> \[OscGroups / Godot\]
- \[OscGroups / XR-Animator\] -\> SuperCollider -\> Godot
- OscGroups -\> SuperCollider -\> \[OscGroups / Godot\]
- XR-Animator -\> SuperCollider -\> \[OscGroups / Godot\]
- \[OscGroups / XRAnimator\] -\> SuperCollider -\> Godot

…

Here we propose a single setup which covers all possible scenarios.
